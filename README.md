# Monte Carlo Probability Simulator

Pure Python (standard library only) simulations of classic probability
problems, verified against their theoretical answers.

## Monty Hall Problem
Simulates the classic 3-door problem to empirically show that switching
doors wins ~2/3 of the time, while staying wins only ~1/3.

### Run it
\`\`\`
python monty_hall.py
\`\`\`

### Sample output
\`\`\`
Win probability while switching: 0.6681
Win probability while staying: 0.33635
\`\`\`
